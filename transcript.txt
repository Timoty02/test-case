  Причина в том, что на этом компьютере есть только один SSH-ключ,
  ~/.ssh/id_ed25519. По ~/.ssh/config он настроен для вашего VPN-сервера и, судя
  по ответу, не добавлен в аккаунт GitHub. Коммит f98937f готов локально,
  origin настроен. Как только появится доступ, хватит одной команды.

  Есть три варианта:

  1. Создать для GitHub отдельный ключ. Я создам ~/.ssh/id_ed25519_github без
     пароля или с паролем, который вы введёте сами. Пропишу его в ~/.ssh/config
     только для github.com, а вы добавите публичную часть в GitHub → Settings →
     SSH and GPG keys. Ключ VPN при этом не затрагивается.
  2. Добавить в GitHub существующий ключ. Это публичная часть
     ~/.ssh/id_ed25519.pub. Так можно, публичным ключом делиться безопасно, но
     тогда один ключ будет и для VPN, и для GitHub.
  3. Отправить по HTTPS через Git Credential Manager: при отправке откроется
     окно входа в GitHub. Для этого поменяю адрес origin на
     https://github.com/Timoty02/test-case.git.

  После того как ключ будет в GitHub, отправка делается так:

  git -C "C:/Users/timot/Desktop/candidate-B" push -u origin main
